# 기획서 구현 시작하기

ZIP을 압축 해제하고 이 폴더를 앱에서 열어 주세요.
같은 프로젝트와 같은 대화에서 01-역할과-설계.md → 02-함께-만들기.md → 03-결과-확인.md 순서로 요청을 붙여넣으세요.
작은 완성마다 01~03을 반복하고, 현재 결과를 저장·공유할 때 04-결과물-등록.md를 사용하세요.
2단계에서 에이전트가 samples/와 사용해보기.md를 만들고 실제 실행 방법을 보여 줍니다. 이 파일들은 초기 ZIP에 미리 들어 있지 않습니다.
스킬은 등록 후 같은 프로젝트 폴더의 새 작업에서 샘플과 실제 호출 요청을 사용해 보세요.
3단계에서는 제공된 예시 그대로 실행한 뒤 입력 하나를 바꿔 결과를 비교하세요.
선택한 도구와 실제 팀 모델은 TEAM.md를 확인해 주세요.
DESIGN.md가 없으면 첫 설계에서 기본 디자인 시안을 선택한 뒤 생성합니다. 조직 디자인이 없어도 진행할 수 있습니다.
