# 매일 아침 8시 루틴 프롬프트

이 PC가 켜져 있고 Aside에 config.local.env에 적은 Google 계정(CLIP_GOOGLE_ACCOUNT)이 로그인되어 있어야 실행됩니다.
아래 내용을 예약 실행의 요청문으로 그대로 씁니다.

```
이 프로젝트 폴더에서 /news-clipping routine 을 실행해 주세요.
- 서울 기준 전날 '아름다운가게' 기사를 모아 요약 초안을 만들어 주세요.
- 수집 결과를 Google 시트 '2026 뉴스클리핑'에 쌓아 주세요. 이미 쌓인 날짜면 건너뛰어 주세요.
- 같은 내용으로 config.local.env에 적은 수신 주소(CLIP_MAIL_TO)로 보낼 메일 초안을 Gmail 임시보관함에 만들어 주세요.
- 마지막에 단계별 결과(성공, 건너뜀, 실패 사유)를 5줄 이내로 보여 주세요.
- 메일은 절대 발송하지 말고, 어떤 방식으로도 공유하지 마세요.
- 어느 단계가 실패하면 이유를 적고, 다음 단계는 이어서 진행해 주세요.
```

## 확인할 곳

- 요약 초안: 프로젝트 폴더의 `output/기준일/clipping-draft.md`
- 시트: config.local.env의 CLIP_SHEET_URL에 적은 시트
- 메일 초안: Gmail 임시보관함 (발송은 담당자가 직접 해요)
